# Prompt Optimization

在 VS Code 的 Codex 聊天输入框中优化提示词：把需求写得更清楚，结合前面的聊天理解指代，支持图片、预览、继续优化和恢复原文。

VS Code 当前源码版本：**0.5.0**，Windows Rust CLI **0.4.3 开发版**。两端共用本机供应商池与 Windows 凭据；每个窗口独立选择连接、模型和思考程度。PowerShell 接入后仍用 `codex` 启动、Ctrl+G 优化，见 [CLI 使用说明](cli/README.md)。

当前源码记录开发进展，不代表全面验收或稳定版发布。升级扩展后需手动重载窗口；共享密钥迁移在新版扩展首次启动时执行，需在实际扩展宿主中验收。

## 功能

- 使用已登录的 Codex、Claude Code，或连接自己的 DeepSeek / Claude API / OpenAI 兼容服务。
- 参考当前窗口已加载的近期聊天，帮助理解“这个”“继续”等说法；也可只优化当前输入。
- 可把输入框附件和参考聊天中的图片一起交给能看图的模型。
- 保存多组账号或 API 连接，在设置页切换；第三方 API 的地址、密钥、模型和思考程度在同一页配置。
- 选择 8 种内置优化模板，也可复制编辑、自建模板、填写变量，导入导出上游格式的模板 JSON。
- 获取与搜索 API 模型；DeepSeek / Claude API 按模型目录识别思考和图片能力，能力未知时明确标注手动设置。
- 独立测试所选 API 模型调用，显示耗时；查询 DeepSeek 官方余额，未适配的服务明确显示不支持。
- 先预览结果，不满意时补充“想怎么再改”，继续优化；失败时保留上一版。
- 同一份草稿连续优化时沿用独立的优化会话，应用或关闭预览后结束，不往原 Codex 聊天中插入优化消息。
- 可开启优化后直接填回输入框，并恢复上一次原文；不会自动发送聊天消息。
- 在本机保存最近 50 条已应用的优化记录，不保存图片。
- 底部常驻“优化提示词”和“优化菜单”，也可选择同时显示输入框内按钮。

## 当前适配范围

当前源码适配目标为 **Windows x64、官方 Codex 扩展 `openai.chatgpt` 版本 `26.51111.21308`**，用于本地会话输入框。2026-11-13 已完成 VSIX 安装、桥接启用及安装文件和备份哈希核对；新版入口、读取聊天和回填仍待重载后实测。

普通扩展无法直接读写另一个扩展的私有聊天输入框。本项目采用版本绑定的本地桥接：启用前核对版本、原文件 SHA-256 和唯一修改位置，备份后修改 Codex 的两个文件，并加入桥接脚本。未匹配的版本会停止接入。

Codex 更新后需要重新核对适配。其他操作系统、云端会话和远程文件路径图片尚未确认支持。

## 安装与使用

1. 获取本项目的 VSIX 安装包。在 VS Code 扩展面板的菜单中选择“从 VSIX 安装”。如从源码打包，见下方说明。
2. 点击底部 **“优化菜单 → 打开优化设置”**，或执行 **“提示词优化：打开设置”**。在“模型与连接”中，使用官方账号时点“使用已登录账号”；自己的 API 服务在表单中填写，点“保存并使用”。
3. 首次使用在设置页顶部点击 **“连接 Codex 输入框”**。未连接时，点击底部“优化提示词”也会打开设置页。
4. 保存工作后，手动执行 **“Developer: Reload Window”**。
5. 先点击目标 Codex 输入框，再点击底部“优化提示词”，或按 `Ctrl+Alt+O`。按 `Ctrl+Alt+Z` 恢复上一次原文。

命令面板仅保留打开设置、优化当前输入、恢复原文和查看优化记录。接入维护和连接管理统一放在设置页。通过旧桌面增强器使用过本工具的用户，应先从托盘退出旧增强器。

设置页分为“常用、模型与连接、模板管理、高级”。“常用”可切换已保存的连接和模板、调整当前模型的思考程度，选择只优化草稿还是结合对话，以及先预览还是直接填回。偏好自动保存，连接和模板表单需明确保存并使用。

从旧版升级时，若页面提示需要更新输入框连接，在设置页顶部先点击“断开连接并恢复原文件”，再重新连接，最后手动重新加载窗口。保留 Codex `26.51021.22027` 的原文件恢复清单，仅用于移除旧桥接；请保留旧版扩展目录和桥接备份，直到恢复完成。

### 配置自己的 API

1. 在“模型与连接”中点击“新建 API 连接”，填写名称和服务类型。地址填写服务商提供的基础地址，需要 `/v1` 时请保留；填写完整的 `/chat/completions` 或 `/messages` 地址也可识别。
2. 填写密钥，点击“获取 / 刷新模型”，在模型输入框搜索选择；列表接口不开放时可直接输入模型 ID。
3. 选择思考程度。目录提供能力时只显示已知档位；否则按协议提供手动设置，并明确提示是否支持仍需服务商确认。图片能力未知时也需手动确认。
4. 可点击“测试模型调用”。它按当前表单配置发送独立短消息，输出上限为 2048 token，可能产生费用；不会读取聊天、草稿或图片，也不会保存到优化历史。模型返回但测试达到上限时会单独提示，不视为完整回复成功。
5. 点击“保存并使用”。测试和获取模型不会自动保存连接；“常用”中的聊天、图片及应用方式等偏好会自动保存。

DeepSeek 官方连接可点击“查询余额”，保留服务返回的币种和金额。中转服务及其他平台尚未接入余额查询。请求可取消；关闭设置页也会取消正在进行的 API 请求。

密钥不会回填到页面；同一连接与地址留空可沿用已保存密钥，更换服务类型或地址需要重新填写。OpenAI 兼容服务如要求 `max_completion_tokens`，可在“接口兼容选项”调整，默认沿用多数兼容服务使用的 `max_tokens`。

### 选择和编辑优化模板

打开优化设置，在“常用”中选择模板并点击“使用所选模板”；查看内容或编辑时进入“模板管理”。模板与模型连接独立保存，切换模型不会重置模板。

| 模板 | 适合的输入 |
| --- | --- |
| 基础优化 | 日常改写，理顺表达，尽量少改。 |
| 需求拆解 | 整理开发目标、范围、约束和验收。 |
| Bug 复现 | 说清现象、复现步骤、期望结果与线索。 |
| 代码审查 | 明确审查范围、关注点和问题输出格式。 |
| 重构需求 | 说明现状、改造目标、兼容边界和验证方式。 |
| 文档 / 说明 | 面向读者整理写作要点和交付格式。 |
| 图像提示词 | 整理主体、构图、光线、风格与画幅。 |
| 视频提示词 | 整理镜头、动作、运镜、时序与节奏。 |

内置模板只读。点击“复制为自定义”后，展开“查看 / 编辑模板内容”，修改规则、用户模板和用途说明，再点“保存并使用模板”。也可从空白新建。基本的保留原意、只改写等规则始终保留。

用户模板用 `{{originalPrompt}}` 引用原文，填入的是 JSON 字符串；不写此占位符时仍会附加原文。可使用 `{{项目名称}}` 等自定义变量，页面会显示填写项，保存或启用前需要填写完整。变量名最多 32 个中英文字母、数字或下划线，单个模板最多 20 个变量；不要在变量中填写 API 密钥。

“导入模板 JSON”支持上游的 `Version: 1 / Templates` 模板包和模板数组，也支持小写字段。导入全部转为自定义模板并生成新 ID，保留原有模板；有无效内容时整批停止。单次最多 5 MB，本机最多保存 100 个自定义模板。“导出当前模板”只导出所选模板定义，不包含变量值、模型连接和密钥。

### 这些设置是什么意思？

| 设置 | 含义 |
| --- | --- |
| 参考前面的聊天 | 结合最近几轮聊天优化，适合继续当前话题；关闭后只看输入框里的文字。 |
| 让 AI 一起看图片 | 把可读取的图片交给模型；关闭后原附件仍留在聊天里。 |
| 思考程度 | 让 AI 想多深入。优先使用模型目录提供的档位；未知 API 能力会标为手动设置，思考越深入通常等待越久。 |
| 优化模板 | 决定提示词怎样整理，独立于模型、思考程度和是否参考聊天。 |
| 优化完直接填回输入框 | 开启后省去预览，仍可恢复；关闭时可在预览里继续优化。两种方式都不自动发送。 |
| 保存优化记录 | 在本机保存最近 50 条已应用的原文和结果，方便回看。 |

默认先预览：满意时点“应用到输入框”；不满意时填写“想怎么再改”，再点“继续优化”。修改要求可留空。多轮优化始终保留原始输入，最后应用时才写入聊天输入框。

### 连续优化怎样使用上下文？

一次优化开始时读取草稿、参考聊天及图片，后续“继续优化”沿用这份背景，提交上一版结果和新的修改要求。每次继续前及写回前仍检查原输入框和参考聊天是否变化；变化后停止续用，需关闭预览重新优化。切换模板、模型连接或优化偏好后如需继续优化，也应重新开始。

- Codex 在独立的临时 thread 上追加 turn，不写入原聊天线程。
- Claude Code 保持本次独立的 stream-json 进程，追加用户消息，不落盘保存该优化会话。
- API 模式在本机维护优化消息历史，每次按 Chat Completions / Messages 协议重新携带历史；不会因此自动免除输入 token 费用。Claude API 的思考内容及签名按协议原样保留。

应用、取消或关闭原输入框时释放本次会话；闲置超过 5 分钟也会结束。最多保留 8 个优化会话、同时执行 4 个请求。调用失败后再次尝试时重新初始化后端，使用原始背景、当前候选和本轮要求继续；不会承诺无限长历史，超出模型限制时会明确报错并保留候选结果。预览会注明此次沿用或新建会话。

### 模型与图片说明

- Codex 模型与思考档位来自客户端返回的目录；目录可能有缓存，实际可用性仍取决于账号。
- Claude Code 可跟随当前模型，也可选择客户端返回的具体模型。单独调整思考程度时需要选定具体模型。
- DeepSeek 默认保留关闭思考的快速改写方式，选择具体档位后才启用思考。Claude API 使用 `output_config.effort`；目录确认支持 adaptive 时同时启用 adaptive thinking。“不额外思考”使用服务对应的关闭参数。
- OpenAI 兼容 API 的手动档位通过 `reasoning_effort` 发送；兼容协议不代表每个模型都支持全部档位，不支持时明确报错。
- 能力目录是最近获取的快照，实际调用还取决于账号权限、额度及服务状态。
- 图片合计最多 8 张，本机单张图片不超过 5 MB。不可读取的图片会明确报错；关闭图片发送时不会声称已理解图片。

## 数据保存与恢复

API 密钥保存在当前 Windows 用户的凭据管理器中，由 CLI 和扩展共同使用，不写入连接 JSON 或日志。Codex / Claude Code 的登录仍由各自官方客户端处理，不提取或迁移其登录令牌。

共享连接以 `%LOCALAPPDATA%\CodexPromptOptimizer\connections.json` 为唯一来源；如设置 `CPO_SHARED_HOME`，两端需使用同一目录。首次使用分别迁移旧 CLI 连接和扩展连接，扩展通过 SecretStorage API 迁移旧密钥，原文件和原密钥保留用于恢复。只合并名称、连接设置和凭据能确认一致的记录，无法确认同一账号时保留独立条目。

当前连接、模型与思考程度按窗口保存，切换不会修改其他已打开窗口。编辑连接资料、清除密钥和删除连接作用于共享池；其他窗口会在下一次读取时获得更新，已删除的连接需要重新选择。并发保存采用系统文件锁、版本检查和原子替换，旧页面无法覆盖新配置；进程退出会释放锁。

自定义模板、当前模板选择和变量值保存在同一目录的 `templates.json`，内置模板来自扩展源码。模板保存同样使用文件锁与版本检查；连接表单和模板表单独立保留未保存的修改，不会因切换另一类设置而自动写入。

聊天记录、草稿和图片仅在主动优化时，按设置交给所选模型服务。输出日志只记录耗时、字符数和数量，不记录提示词正文或密钥。启用优化记录后，原文和结果保存在 VS Code 本机扩展存储中。

接入备份与恢复记录也位于本扩展的 VS Code globalStorage 目录。移除或卸载前，在设置页顶部点击 **“断开连接并恢复原文件”**，再保存工作并重新加载窗口。恢复会核对文件，避免覆盖已被其他方式修改的内容。

模型与协议实现参考 [DeepSeek 模型目录](https://api-docs.deepseek.com/api/list-models/)、[DeepSeek 思考模式](https://api-docs.deepseek.com/guides/thinking_mode/)、[DeepSeek 余额](https://api-docs.deepseek.com/api/get-user-balance/)、[Claude 模型目录](https://platform.claude.com/docs/en/api/http/models/list)、[Claude Messages API](https://platform.claude.com/docs/en/api/http/messages/create) 和 [OpenAI Chat Completions](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

## 从源码打包

扩展没有额外的运行时 npm 依赖，但 Windows 安装包需要携带 Rust 原生存储程序。从源码打包需要 Rust 1.94+ 和 Node.js 22+：

```powershell
git clone https://github.com/Lele-bigLe/Prompt-Optimization.git
cd Prompt-Optimization
cargo build --release --locked --manifest-path cli/Cargo.toml
New-Item -ItemType Directory -Force native | Out-Null
Copy-Item cli/target/release/prompt-optimizer.exe native/prompt-optimizer.exe
npx --yes @vscode/vsce package --no-dependencies
```

打包完成后，从 VS Code 安装生成的 `.vsix` 文件。打包工具说明见 [VS Code 官方文档](https://code.visualstudio.com/api/working-with-extensions/publishing-extension)。

```text
core/       优化提示词、模型调用和官方客户端适配
vscode/     输入框接入、设置页、预览和恢复
cli/src/    Rust 终端界面、协议桥接和共享存储
native/     安装包携带的 Windows 原生程序
```
