# Prompt Optimization

在 VS Code 的 Codex 聊天输入框中优化提示词：把需求写得更清楚，结合前面的聊天理解指代，支持图片、预览、继续优化和恢复原文。

当前版本：**0.3.0，本地试用版**。目前专注 VS Code，CLI 独立入口暂缓开发。

## 功能

- 使用已登录的 Codex、Claude Code，或连接自己的 DeepSeek / Claude API / OpenAI 兼容服务。
- 参考当前窗口已加载的近期聊天，帮助理解“这个”“继续”等说法；也可只优化当前输入。
- 可把输入框附件和参考聊天中的图片一起交给能看图的模型。
- 思考程度按所选 Codex / Claude Code 模型提供的档位选择。
- 先预览结果，不满意时补充“想怎么再改”，继续优化；失败时保留上一版。
- 可开启优化后直接填回输入框，并恢复上一次原文；不会自动发送聊天消息。
- 在本机保存最近 50 条已应用的优化记录，不保存图片。
- 默认使用 VS Code 底部状态栏入口，也可选择输入框内按钮。

## 当前适配范围

当前适配 **Windows x64、官方 Codex 扩展 `openai.chatgpt` 版本 `26.51021.22027`**，用于本地会话输入框。

普通扩展无法直接读写另一个扩展的私有聊天输入框。本项目采用版本绑定的本地桥接：启用前核对版本、原文件 SHA-256 和唯一修改位置，备份后修改 Codex 的两个文件，并加入桥接脚本。未匹配的版本会停止接入。

Codex 更新后需要重新核对适配。其他操作系统、云端会话和远程文件路径图片尚未确认支持。

## 安装与使用

1. 获取本项目的 VSIX 安装包。在 VS Code 扩展面板的菜单中选择“从 VSIX 安装”。如从源码打包，见下方说明。
2. 命令面板执行 **“Codex 提示词优化：打开设置”**，点击“更换 AI 和模型”。使用已登录账号时不用在此填写密钥；自己的 API 服务需要填写连接信息。
3. 首次使用执行 **“Codex 提示词优化：启用输入框按钮”**，安装输入框接入。
4. 保存工作后，手动执行 **“Developer: Reload Window”**。
5. 先点击目标 Codex 输入框，再点击底部“优化提示词”，或按 `Ctrl+Alt+O`。按 `Ctrl+Alt+Z` 恢复上一次原文。

启用接入后，底部“优化提示词”旁的齿轮也能打开设置。通过旧桌面增强器使用过本工具的用户，应先从托盘退出旧增强器。

### 这些设置是什么意思？

| 设置 | 含义 |
| --- | --- |
| 参考前面的聊天 | 结合最近几轮聊天优化，适合继续当前话题；关闭后只看输入框里的文字。 |
| 让 AI 一起看图片 | 把可读取的图片交给模型；关闭后原附件仍留在聊天里。 |
| 思考程度 | 让 AI 想多深入。只列出当前模型提供的档位，思考更深入通常等待更久。 |
| 优化完直接填回输入框 | 开启后省去预览，仍可恢复；关闭时可在预览里继续优化。两种方式都不自动发送。 |
| 保存优化记录 | 在本机保存最近 50 条已应用的原文和结果，方便回看。 |

默认先预览：满意时点“应用到输入框”；不满意时填写“想怎么再改”，再点“继续优化”。修改要求可留空。多轮优化始终保留原始输入，最后应用时才写入聊天输入框。

### 模型与图片说明

- Codex 模型与思考档位来自客户端返回的目录；目录可能有缓存，实际可用性仍取决于账号。
- Claude Code 可跟随当前模型，也可选择客户端返回的具体模型。单独调整思考程度时需要选定具体模型。
- 自定义 API 暂不查询思考档位能力，保持现有调用方式；DeepSeek 使用关闭思考的快速改写方式。
- 图片合计最多 8 张，本机单张图片不超过 5 MB。不可读取的图片会明确报错；关闭图片发送时不会声称已理解图片。

## 数据保存与恢复

API 密钥保存在 VS Code SecretStorage 中。Codex / Claude Code 的登录由各自官方客户端处理，本扩展不提取或保存其登录令牌。

聊天记录、草稿和图片仅在主动优化时，按设置交给所选模型服务。输出日志只记录耗时、字符数和数量，不记录提示词正文或密钥。启用优化记录后，原文和结果保存在 VS Code 本机扩展存储中。

接入备份与恢复记录也位于本扩展的 VS Code globalStorage 目录。移除或卸载前，先执行 **“Codex 提示词优化：移除输入框按钮”**，再保存工作并重新加载窗口。恢复会核对文件，避免覆盖已被其他方式修改的内容。

## 从源码打包

扩展源码没有额外的运行时 npm 依赖。使用当前官方 `vsce` 打包需要 Node.js 22 或更高版本：

```powershell
git clone https://github.com/Lele-bigLe/Prompt-Optimization.git
cd Prompt-Optimization
npx --yes @vscode/vsce package --no-dependencies
```

打包完成后，从 VS Code 安装生成的 `.vsix` 文件。打包工具说明见 [VS Code 官方文档](https://code.visualstudio.com/api/working-with-extensions/publishing-extension)。

```text
core/       优化提示词、模型调用和官方客户端适配
vscode/     输入框接入、设置页、预览和恢复
```
